Refund & Cancellation Policy

Last updated: 27 October 2026

Ready-made PPTs

  • These are digital files available instantly, so we do not give refunds after the file is downloaded.
  • If the file is broken, does not open, or is clearly different from the preview, tell us within 7 days. We will send a fixed file or a replacement, and if we cannot, we refund the full amount.
  • If money was debited but you did not get the PPT, we deliver it or refund the full amount.

Custom PPTs

  • You can cancel for a full refund before we start working.
  • After work starts, we offer free changes as agreed instead of a refund.

How refunds are paid

Approved refunds go back to the same payment method (UPI / card / bank) within 5–7 working days.

How to ask

Email or WhatsApp us with your name, mobile number and payment reference.
